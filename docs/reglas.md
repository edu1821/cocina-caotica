# Definition of Done

- [ ] Corre en un celular real, no solo en el navegador del escritorio
- [ ] Está desplegado y otro del equipo lo probó
- [ ] Sin errores en la consola
- [ ] El PR está revisado y mergeado a main
- [ ] Si toca la lógica del juego, tiene al menos un test
